# CineFactory Niche Operating Systems

Each niche owns its audience, competitor, SEO, format, production, packaging,
retention, risk and analytics state. Shared company/filmmaking principles live
outside these folders. Cross-niche promotion requires evidence.

## Slow English → A2 → Magical Witch Family Stories → Bell & Leaf

The Bell & Leaf series is **one magical-family stories subniche under Slow English A2**, not the entire Slow English catalog. Its canonical profile remains `config/niches/slow_english_a2/` (backward-compatible path). Its entrypoint is `python scripts/slow_english_a2_preflight.py --shots examples/slow_english_a2_ep001_preflight.json --out <your-output-directory>`. It uses the existing CineFactory Studio services and shared character/location/prop registries; generated image concepts and pending voice samples are **not** production-approved. PR #4 was merged to main and supersedes closed PR #2/#3; PR #5 merged voice casting descriptions. This taxonomy clarification does not create another project.
