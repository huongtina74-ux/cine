# Quality Benchmark & Release Gate
Compare the SAME hard original shot across methods with controlled duration, visual/audio requirements and output FPS/resolution. Hard-fail unreliable character rigs/identity, motion, camera geography, narrative continuity, voice sync, lighting, SFX, unlicensed assets and unsafe code. Record actual rendered output paths + hashes, provenance, human review, time, retries, peak VRAM, rework, cost and accepted seconds/hour. If media is not actually inspected, mark BLOCKED. Never bypass installation, budget or rights gate. Return primary method and fallback only when actual pilots pass.
