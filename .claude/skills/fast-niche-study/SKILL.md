# Fast niche study (time-boxed)
Budget: 10-15 reference videos, ~2 hours, one report. Production of ORIGINAL episodes never waits for this.
1. Discovery: public metadata only (titles, views, publish date, channel age, duration). vidIQ read-only tools if connected (`vidiq_outliers`, `vidiq_keyword_research`, `vidiq_channel_videos`).
2. Pick 3 outliers + 2 median videos. Study what is legally viewable; label every claim OBSERVED / INFERRED / UNKNOWN. Do not download third-party media.
3. Output `docs/niches/<niche>_brief.md` with: audience, promise, hook pattern (first 5 s), episode length, pacing (cuts/min), recurring format beats, thumbnail/title patterns, what is saturated, 3 ORIGINAL format ideas we can produce with our current pipeline, and the cheapest pilot to test each.
4. Stop. Hand to showrunner. Do not create new code modules for research.
