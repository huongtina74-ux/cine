# CineFactory Media Tool Router (v219)

Use project local MCP `studio_status`, `comfyui_local_status`, `comfyui_local_capabilities`, `comfyui_local_queue` and `claude_external_connector_plan` BEFORE recommending new AI, editing software or MCP. The first three Comfy tools query only GET endpoints at `127.0.0.1:8188`; do not assume generation or license authority.

Search `search_technology`, `niche_production_brief`, `mcps_for_niche` to compare existing Blender (rig, scene, camera, animation), ComfyUI (local visual), FFmpeg/Remotion (editing), source footage/audio and third-party online models. Use per-scene decisions; no global single-model selection.

Before proposing a third-party server:
1. Confirm actual client/runtime installed and official or pinned repository/version.
2. Isolate execution, code writing, network, filesystem and OAuth tokens.
3. Deny paid or partner generation, arbitrary `bpy`, unreviewed custom nodes and model download unless the owner explicitly authorizes budget, scope and risks.
4. Keep Blender 4.5 current factory untouched; Blender Lab MCP requires 5.1+ sandbox.
5. OpenArt/Higgsfield are optional cloud SaaS and credits are used; Google Flow web is not a documented Claude Code MCP.
6. If an external MCP has not been installed, connected and smoke-tested, label it NOT_CONNECTED; a running Claude Desktop extension does not establish Claude Code connectivity.
7. Compare real shot pilots with QC, sound, character consistency, resolution, VRAM and human rework. Maximize accepted finished seconds/hour only among quality-passing methods.

Do not turn any MCP research/status query into a paid creative call. Report `CONNECTED_READ_ONLY`, `OPTIONAL_DISABLED`, `NEEDS_APPROVAL`, or `UNAVAILABLE` with evidence rather than inventing execution support.
