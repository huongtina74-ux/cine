# Story development

Use the selected CineFactory checkout. If required tools, documents or media are unavailable, report the missing dependency and complete only supported analysis; do not invent command results or schema fields. Exercises below are evaluation scenarios, not authorization to render, spend or publish.

Read the niche format, series bible, recent episodes and confirmed learnings. Preserve approved audience and educational goals.

## Method
For evidence-bearing production work, read [references/production.md](references/production.md). It maps this specialty to the executable packet checks, source/use limits and evaluation procedure. In CineFactory, available tools are `tools/cf_professional.py` and the existing stage SOPs.

1. Write the episode's distinct promise and the protagonist's observable goal. Name the obstacle, choice, consequence and change by the ending.
2. Draft a beat table: incoming state, action/choice, consequence, new information, emotional change, plant/payoff and estimated duration. A coincidence may create trouble; do not let it resolve the central problem without setup.
3. Keep a knowledge/state ledger: who knows a fact, when it becomes known, where a prop is, and which choice changes the situation. Check the earliest broken transition before rewriting later scenes.
4. For educational stories, attach each teaching objective to an action or exchange; distinguish language-level checks from actual listener comprehension.
5. Read dialogue for intention and subtext. A line that repeats visible information needs a stated reason. Compare the concept and outcome against channel history.
6. Hand a stable story to the director. Keep shot-card ownership with that role. Existing schema and format checks remain necessary but cannot judge emotional payoff.

## Deliverable and exercise
Deliver a script revision, beat table, state ledger and unresolved questions. In CineFactory use the existing producer's check mode and originality tool after inspecting their current help.

Exercise: a child loses a ticket and a stranger instantly supplies a replacement. Revise with a planted resource and a meaningful choice, while retaining the owner-approved ending. Pass when a reader can trace the solution to earlier events and the protagonist contributes to it.
