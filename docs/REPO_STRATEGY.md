# Repository / workflow / skill integration strategy

CineFactory studies complete A-to-Z factories as whole production systems **and** studies their strongest subsystems. It does not automatically discard a factory merely because it contains a cloud provider; the useful production logic may be retained while the paid executor is replaced by a local CineFactory executor.

Candidate technology receives one treatment after full production-path audit:

- **USE AS-IS** — already compatible and safe behind CineFactory authority.
- **WRAP** — keep the subsystem largely intact but adapt data/state to CineFactory contracts.
- **FORK/MODIFY** — preserve a strong A-to-Z workflow while replacing cloud/state/security layers.
- **LEARN/REIMPLEMENT** — absorb the production principle or algorithm when direct inclusion is unsuitable.
- **LAB** — benchmark only; no production authority.

## Current sources of production thinking

- OpenClaw — executive agent/orchestration.
- ai-film-skills — directing, performance, blocking, cinematography, previs.
- Shuohao / drama-skills — structured writing, assets, deterministic gates, continuity locks and stage ownership.
- CineCrew / MovieAgent / DramaDirector / AniMaker / ShotPlan — film planning, critic loops, geometry and candidate selection research.
- ArcReel / LocalMiniDrama / Wind Comic / Jellyfish / ai-video-studio — durable jobs, stale dependency propagation, asset/state and reliability patterns.
- ComfyUI ecosystem — local execution graph and workflows.
- OpenChatCut — editorial timeline and post runtime.
- FireRed/OpenStoryline and professional-editor projects — reusable editing logic, rough-cut and finishing patterns.

No repository, workflow or skill may become a second canonical project database, second production JobLedger, second Director authority or second editorial timeline.
