# v1.6 Execution Completeness

## Design target

v1.6 closes the largest v1.5 gap: the compiler already understood scenes, props, crowd, camera coverage and events, while the worker executed only a subset. The runtime path is now:

`EpisodeSpec → EpisodeAssembler → BlockExecutionPlanner → PersistentBlenderWorker → local Visual QC → timeline/editor`.

## Quality-first, zero-API default

`rtx3060_quality` is the default quality profile. It favors consistent local rendering over cloud generation: AgX color management, three-point key/fill/rim light, DOF, motion blur hooks, contact shadows/AO where supported, higher sample targets, and 32 Mbps local shot encoding.

No image/video/TTS cloud API is introduced by v1.6. The existing `ZERO_METERED_API` production policy remains the hard cost boundary.

## Execution coverage

### Scene runtime

- External `.blend` collection: loaded once and cached in the persistent Blender process, then copied per shot.
- No external scene: procedural local set selected by `procedural_kind` (`room`, `classroom`, `street`, `arena`).

### Character performance

- External rig actions continue to use cached Blender actions/NLA.
- Procedural fallback actors now have legs and expanded walk/run/jump/fall/turn/reaction behavior.
- Crowd cues are normalized into the same action/expression stream as foreground actors.
- `facing_target` is resolved after actor instantiation.

### Props

A resolved prop binding now means: instantiate → attach to armature bone/procedural socket → apply offset → visible during the binding interval → hidden outside it.

### Camera

Camera patterns now retain `shot_size`, `target_mode`, `framing_margin`, `motion_strength` and `dof_fstop`. Runtime supports static, push-in, pull-out, track, orbit and snap-like moves against a deterministic focus target.

### Events

Local VFX implementations exist for `impact_flash` and `sparkle_burst`. Every shot also writes an `.events.json` sidecar, and episode assembly merges these into an episode event manifest so the later audio director can resolve Foley/SFX without rebuilding the render.

### QC

Technical QC still verifies duration/resolution/codec. `BlockVisualQC` adds local FFmpeg `blackdetect` and `freezedetect` checks. Semantic contact/identity QC remains a later local-VLM/geometry milestone; v1.6 does not pretend those are solved by the signal detector.

## Next milestone

v1.7 should add the Minecraft/Voxel runtime adapter, world-interaction primitives, structure generation, replay/state recording and multi-camera recapture. It should consume the same higher-level Episode/Story contracts rather than fork a second creative pipeline.
