## 4. Concrete P0 software/design gaps (must be fixed without weakening fail-close)
**P0-A — Baseline governance must not depend solely on a supplied niche.** `cinefactory/studio/company.py` in `CompanyOrchestrator.build_blueprint` sets professional governance to `bool(safe_project.niche)`; stage blueprint strips PROJECT_INTAKE, PORTFOLIO_GREENLIGHT, CORPORATE_PREFLIGHT and specialist stages in generic mode. Verified direct stage counts: generic animation 21, Minecraft animation 32, Roblox animation 32, Long Slide animation 25. Generic prompt cannot silently bypass common film-quality gates. Keep domain-specific augmentations but make company-wide standards universal.

**P0-B — Logic gate is not an actual independent story/continuity reviewer.** `cinefactory/studio/company_handlers.py`, `logic`: always returns `passed=True`, `findings=[]` after simply constructing sequential scene transitions. Advanced `SCRIPT_REVIEW` exists for selected professional story niches only; generic or Long Slide can lack it. Replace boolean self-approval with scene-state causality, contradiction, 180-degree/screen-direction/performance continuity checks and source-bound independent reviewer, UNKNOWN/BLOCKED on missing evidence.

**P0-C — Distinguish diagnostic slate from accepted production.** `FilmHandlerConfig.production_mode` defaults to `"slate"` with `allow_diagnostic_slate=True`. Slate diagnostics may validly test infrastructure but must not be presented as actual film content, particularly in final master packaging. Add explicit signed run intent and nonpromotable diagnostic tagging at each artifact, downstream master and gallery.

**P0-D — Final watchability and approval are incomplete.** `company_handlers.py:final_qc` uses `self.mastering.qc.video(...,require_audio=False)`; `post/mastering.py` performs an FFmpeg format/master pass and technical QC only. `require_human_topic_approval`, `require_human_spend_approval`, `require_human_final_approval` default to False, generating `AUTO_APPROVED`. Final commercial release needs a separate authenticated owner/independent-QC gate and rights/privacy/disclosure review. No claim that video auto-upload currently exists.
