# CINEFACTORY v1.6.31 — PROFESSIONAL PRODUCTION SELECTION COUNCIL

**Status:** RESEARCH/ADVISORY IMPLEMENTED + TARGETED TESTS. Production execution is NOT enabled by this change.  
**Date:** 2026-10-09  
**Goal:** Select the best evidenced video-production method for *each niche, production department, scene and shot* subject to visual/audio quality floors, hardware, time, cash cost, IP rights, original content, child safety, and tool readiness. Never claim universal absolute best when comparative tests do not exist.

## Nonnegotiable decision hierarchy

**1. Narrative/artistic/curriculum requirement first.** Each niche has a separate quality rubric: original IP, acting/rigging, song choreography, game physics, voice clarity, natural recording or factual accuracy. The format determines tools, not the other way around.

**2. Identify all feasible methods.** Research official docs, GitHub source/release/license, public model cards/checkpoints, locally available binaries, legitimate SaaS/API options if user permits, benchmark studies, asset licences, integration/MCP adapters, and existing in-house reusable workflows. No paid API/connector/install is activated without consent.

**3. Hard veto before score:** executable proof and version, appropriate licence for the proposed business model, source assets/music/voice rights, safety/children policy, GPU/VRAM and RAM limits, ability to control scene semantics/identity, observed output format, and required audio/quality. Unknown is not PASS.

**4. Real scoped comparison:** make *the same representative shot* with each feasible candidate. Use common inputs and a sealed benchmark set. Record render frames, audio stems, quality review/negative controls, wall time, GPU/VRAM peak, manual touch time, retries, candidate count, storage, electricity, subscriptions or API usage. Cost is **USD per accepted minute**, not per raw generated minute.

**5. Quality floor before cost:** only candidates that meet niche-specific visual/audio quality, originality and consistency floors can compete. Among viable options report (a) top quality, (b) lowest measured cost, (c) fastest, (d) balanced selection and (e) Pareto frontier. Never compare missing metrics as zero cost or excellent quality.

**6. One tool per workload when it makes sense, multiple when it helps.** A single video may combine Blender facial performance, hand-authored music, motion graphics and native FFmpeg editing. Camera, FPS, colour management, actor IDs, audio time-base, subtitle and license bundles must conform at scene assembly boundaries.

**7. Evidence expiration and releasability:** re-run a benchmark after version/model/hardware/workflow changes. An observational model recommendation remains advisory until existing company release gates, creative reviews and copyright controls separately approve it. Council does NOT trigger a render, install, publish, pay or automatically approve the production.

## 13 niche-specific tool decision examples (proposals only)

| Niche | Preferred first pilot method | Alternative to benchmark | Must-have veto/quality gate |
|---|---|---|---|
| Minecraft original animation | Blender current voxel rigs + persistent worker | Runtime Minecraft scenes when actual gameplay required | actor identity, high-quality acting, shot continuity, asset/game rights |
| Roblox R6 original | Blender worker R6 + facial animation | Roblox Studio runtime when genuine gameplay is the core | rig semantics, skin, identity, movement, rights |
| Preschool 3D original musical (CoComelon-style genre) | **Original** Blender organic facial rig + human-approved music-first timeline | licensed 3D realtime renderer + music direction / compositing | original character/song/IP, age and curriculum review, singing visemes and choreography |
| Animal 3D animated stories | Blender animal rigs and behaviour library | qualified real-time simulation and original animal assets | animal anatomy, expressive acting, collision and distinct IP |
| Long Slide Physics | Godot under MIT (candidate, absent PATH) + Blender original assets | Blender physics for cinematic shots | physical collisions, obstacle outcomes, replayable deterministic seed |
| GTA authentic gameplay | licensed game runtime and recording/capture | engine-driven simulation when *not* claiming genuine GTA footage | game/publisher rules, authentic capture, no stolen media |
| AI drama and fantasy | ComfyUI verified local model **only after** video workflow benchmark | Blender-controlled performance and compositing | character continuity, lip-sync, model/checkpoint commercial rights and 12GB fit |
| 2D character animation | OpenToonz (candidate, BSD) or Blender Grease Pencil | Remotion for 2D motion graphics when its company licence fits | art originality, drawings, readable acting, timing |
| Hands/object ASMR sleep | **real close-mic footage** + audio restoration/FFmpeg | asset-based visual if obviously synthetic and appropriate | recording rights, low noise floor, no harsh transients, authenticity |
| Senior audio storytelling | original story + authorized narration + audio mastering | locally licensed voice TTS vs human narration (A/B test) | intelligibility, pacing, rights and listener experience |
| Rain/sleep/white noise | authorized ambience/capture + FFmpeg | procedural sound engine with mastered non-repetitive ambience | source licence, uninterrupted loop, no sudden sounds/flicker |
| Silent fishing/nature | licensed first-party footage + audio post | other original locations, authorized documentary assets | field authenticity, property/person/location rights, safe real content |
| English language learning | curriculum-reviewed script + authorized narration + graphics | human/AI dubbing with linguist QA and 2D/3D exercises | accurate grammar, pronunciation, readable subtitles |

Never assume Blender creates a believable hand-ASMR video better than actual photography, nor that a generative model will sing original lyrics in exact time more reliably than a controlled organic rig. A costlier renderer is justified only if a blinded/human-reviewed experiment shows material output benefit for that shot and it fits the budget.
