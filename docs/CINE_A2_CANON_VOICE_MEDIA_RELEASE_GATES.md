# Bell & Leaf — Fixed 10-Second Source-Locked Pipeline

## Asset governance
The ten canonical original character roles and 90 source-pixel crops can be recovered LOCALLY from user-owned original images only when SHA/RGBA signatures match pinned source values. Re-encoded PNG byte SHA differs from private canonical originals; exact pixels are verified. Source crops do not constitute approved new CGI reverse-angle views. NEVER upload original PNGs, WAVs, media, model weights or local private files to the public GitHub repository. Independent room/prop plates (483 and 756 slots) require separate approval.

## Audio
VoxCPM2 emits synthetic casting WAV candidates and a proposal for ten distinct character voices. The A2 listening versions are pitch-preserving time-stretched previews only, not approved voice masters. Production dialogue fails closed unless exact speaker tag, licensing, approved sample SHA, voice ID, model version and authorized reference exist. Rhubarb 1.14 CLI emits mouth cues bound to the exact WAV SHA but does not itself prove lip-sync animation.

## Muse quality gate
A shot is exactly 10 seconds (240 frames at 24fps), 16:9 >=720p. Require approved character identity references, room and prop plates, licensed reference WAV, voice mapping, cue timing, genuine motion and human artistic review. A provider task receipt tied to video SHA is required, but a local JSON receipt is not independent platform verification. Media gate deliberately NEVER production-authorizes solely on local receipts. Provider integration and real media must be verified separately.

## CI
Private character sources are intentionally absent in cloud CI; local source-only validation skips if the originals are not installed. Synthetic audio/video smoke samples must never be accepted as production.
