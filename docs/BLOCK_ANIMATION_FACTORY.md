# Block Animation Factory 1.6

`EpisodeSpec → EpisodeAssembler → reusable libraries → BlockExecutionPlanner → durable GPU queue → persistent Blender worker → technical + local visual QC → incremental timeline → FFmpeg episode assembly`.

The factory separates reusable production mechanics from story truth. `blocked_reference_tokens` remains an explicit guard against copying reference branding or named story material.

v1.6 is quality-first and zero-metered-production-API by default. Scene, prop, crowd, camera motion, DOF and VFX contracts now reach the renderer. For one RTX 3060 12GB, keep one hot Blender GPU lane, prefill shot work, and run IO/edit/QC concurrently. Real seconds/frame and final beauty quality must be measured on the target PC.
