# CineFactory Professional Company OS v1.6.7

CineFactory now separates three layers:

1. **Company functions** — strategy, finance, legal, people, growth/SEO, data, technology, risk.
2. **Permanent craft departments** — story, direction, cinematography, production design, performance, technical direction, production, editorial, audio, color, QC, R&D.
3. **Niche operating systems** — each niche owns audience, competitors, SEO, formats, production recipes, packaging, retention, risk and analytics.

## Operating principle

Universalize only what is truly universal.
Specialize everything that depends on audience, format, platform, production mode or niche.

## Creative hierarchy

Narrative:
PROJECT -> ACT/SEQUENCE -> SCENE -> BEAT -> SHOT -> FRAME EVENT

Non-narrative formats use niche-specific content units, for example:
- Long Slices: run -> obstacle segment -> event -> camera shot
- ASMR: session -> trigger block -> trigger action -> shot
- Audio storytelling: chapter -> scene -> story beat -> audio segment
- Fishing: session -> fishing event -> action -> camera shot
- Rain/Sleep: environment -> ambience segment -> loop/variation block

## SEO evidence rule

Competitor CTR, retention, RPM, CPM and revenue are not public facts.
SEO observations must distinguish:
- PUBLIC_FACT
- ESTIMATE
- INFERENCE
- UNKNOWN

## Maturity rule

Architecture alone is not evidence of Disney-level execution.

Department maturity:
L0 UNSPECIFIED
L1 DOCUMENTED
L2 CONTRACTED
L3 TESTED
L4 PRODUCTION_READY
L5 BENCHMARK_LEADING

L5 requires benchmark evidence, not self-description.
