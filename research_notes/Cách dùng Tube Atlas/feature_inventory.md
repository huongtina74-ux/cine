Research date: 2026-11-13. Method: read-only (no sign-up, login, trial or download). Sources are the vendor's own pages (tubeatlas.com sales page, the upsell page, the affiliate page, the AppBreed help-video index, the AppBreed public version history), plus a few third-party reviews, each labelled. ## Q1. What is Tube Atlas, and which modules actually exist?

### Takeaway
Tube Atlas is a desktop app from AppBreed, by developer Dave Guindon, that runs on Windows and macOS. It is bought once and has no cloud database. It is NOT a SaaS "niche finder / outlier database" like TubeLab or TubeMind. It has 12 core tools: Keyword Generator, Trends, Videos (Video Analyzer), Browse & Extract, Channels, Video-to-Text, Comments, Content Spinner, Title Generator, Video Downloader, Tag Analyzer and Title Analyzer. On top of those it has helper features: the Video Details window, a hashtag generator, filters, Shorts, in-video ads, related and unlisted videos, AI text tools, an ad-free player and HTML reports. The latest version is **1.0.6.7, released 12 Nov 2026**.

### Inferences
- If the owner expects TubeLab-style features (outlier multiple, RPM filter, faceless, a niche database), Tube Atlas will not provide them out of the box. They can only be approximated by hand, by sorting and filtering the Videos and Channels grids (see Q3).
- The product's name collides with the OSS project. Anyone searching "Tube Atlas outlier finder" may land on the GitHub project, not the paid app.

### Gaps
- No official changelog entry introduces features beyond 1.0.6.7. There is no "version 2" of Tube Atlas itself; the upsell page talks about "major version 2", but that refers to the upsell apps.
- The public Freshdesk knowledge base has no articles, only the ticket portal. — [appbreed.freshdesk.com/support/solutions](https://appbreed.freshdesk.com/support/solutions)

## Q2. What does each module contain: inputs, buttons, filters, sorts, columns and metric definitions?

### Takeaway
Every tool fills a **data grid**. The shared grid features are: one-click column **quick filters**, **custom filters** on any column, saved and loaded **filter files**, column sorting, **column configuration**, right-click menus, and re-extraction of rows. The Videos grid has 35 official columns, plus an "Is Shorts" column added later. The Channels grid has "27+" columns. Earnings are an *estimate*, and no formula is published.

### Inferences
- "Outlier"-style analysis is only possible by hand. Combine **Average Views per Day**, **Total Video Views** and **Total Channel Subscribers** in a custom filter, and sort by Average Views per Day. There is no computed views-to-subscribers ratio column; none is listed.
- "Revenue" is almost certainly views × an assumed CPM or RPM. The formula and any user-adjustable CPM setting are not stated publicly. Help video 27 probably explains it.
- No sort options are listed beyond clicking a column header. Every column is likely sortable.

### Gaps
- The exact formulas for Estimated Video Earnings, Estimated Earnings per Day, Readability and Grade Level are not published. Help video 27 could not be played here.
- The full list of the 27+ Channels-tool columns is not published in text form; only the columns named in changelog fixes are confirmed.
- Whether the grids export to **CSV**: the only confirmed exports are emails to CSV/TXT, interactive HTML table and feed reports, saving and loading the app's own data files, chart images, and Save to HTML in Video-to-Text. A general grid-to-CSV export was **not** found in official text.
- The settings on the Videos search (results count, sort, upload-date filters) are not documented beyond "change any settings". — [imnights](https://imnights.com/tube-atlas-review)
- The exact 6 hashtag methods are not listed in text.

- Keyword step: "Add in your seed keyword… choose your search range". Add volume from free sources or Keywords Everywhere. — [imnights](https://imnights.com/tube-atlas-review); [help videos 3–5](https://appbreed.com/help-videos-tube-atlas)

### Suggested niche-research playbook (INFERRED from the documented features above, not an official SOP)
1. **Keywords tab**: type the seed (for example "slow english story"), pick a country, run it. Import search volume (video 4) or use Keywords Everywhere if you pay for it. Right-click → copy comma-separated keywords.
2. **Trends tab**: import the keyword list, choose YouTube search and a country/time period. Sort by the average or the slope to find rising terms. Click a sparkline for the full chart, and save the chart image. Expect throttling.
3. **Videos tab**: search each top keyword with the red Search button, or press **Trending Videos**, or use **Browse & Extract** (YouTube search with its own filters such as upload date, type Shorts, duration; then auto-scroll; then extract links) to collect 1,000+ videos.
4. Turn on the **Is Shorts** column to separate Shorts from long videos. Use quick filters on Publish Age in Days (for example < 90), Total Channel Subscribers (for example < 50k), and Average Views per Day (high). That gives a manual "outlier" screen. Save it as a **custom filter file** so you can reuse it.
5. Select the winners → **Get Related Videos** to widen the set → **Extract Missing** / re-extract rows where data failed.
6. **Analyze tags** and **analyze title word combinations** on the filtered list → generate hashtags.
7. **Channels tab**: import the channels of the winning videos (Browse & Extract or content extraction) → "analyze all videos in channel" to see each channel's best videos and its consistency.
8. **Comments tab** on 2–3 top videos: filter for questions, check top word combinations to find viewer needs and complaints.
9. **Save data** (the app's own data file) and **preview/save table report** as an interactive HTML file to share. Use File → Open data folder to find the files.
- "Compare" means opening saved data files side by side or using the HTML reports. There is no built-in compare view or saved-collection feature in the official text.

### Takeaway
There is a single tier with no feature gating. Every tool comes with the one-time license. Extra cost comes only from **separate upsell apps** and **third-party API accounts** (Keywords Everywhere, Gladia/Deepgram).

- Price: list $67 one-time. The sales page shows $47 with coupon **TUBE20**. "No monthly or recurring payments". 30-day money-back guarantee. Free version-1 updates "for LIFE". — [tubeatlas.com](https://tubeatlas.com/)

## Q5. Hidden or advanced features, shortcuts, URL parameters, API, limits and risks

### Takeaway
There is no public API, no URL parameters and no documented keyboard shortcuts. The "hidden" power is in **right-click menus**, **double-click actions**, **Browse & Extract with auto-scroll**, **filter files**, **re-extract / Extract Missing**, and **multiple YouTube logins**. Reliability depends on scraping YouTube and Google.

### Cited findings
- Double-click shortcuts: double-click an Image cell to open Video Details. Double-click a comment cell to preview the comment. Click a Video ID cell or the details thumbnail to play the video in the ad-free player. — [tubeatlas.com](https://tubeatlas.com/); [version history](https://appbreed.com/apps/api/app-download.php?aid=26)
- Right-click menus: re-extract rows, ReExtract NOT EXTRACTED rows, copy hashtags, copy comma-separated keywords, Import Keywords, Convert to video embed codes, word replace (Spinner). — [version history](https://appbreed.com/apps/api/app-download.php?aid=26)
- Email and phone extraction from descriptions, with Save emails to CSV/TXT (video 28). — [tubeatlas.com](https://tubeatlas.com/); [version history](https://appbreed.com/apps/api/app-download.php?aid=26)
- Risks noted by a reviewer: "Extraction depends on YouTube and Google, and the Trends tool is restricted"; contact extraction "raises privacy and consent questions"; the spinner and transcript tools "can breach copyright and YouTube's rules". Score 6.3/10. — [SaaSPic](https://saaspic.com/tools/tube-atlas/)
- The release pace is mostly maintenance; the history shows repeated breakages after YouTube changes (for example 1.0.5.5, 1.0.6.4, 1.0.6.7). — [version history](https://appbreed.com/apps/api/app-download.php?aid=26)
- Some unauthorized "nulled" copies of Tube Atlas circulate on piracy forums. They are not a legitimate source and should not be used. — (observed in search results only; deliberately not cited as a source)

### Inferences
- **Fit with CineFactory house rules (CLAUDE.md):** the Video Downloader (downloading third-party videos), the Content Spinner and the "legal content" transcript rewriting conflict with the rule "Original IP only… no downloading third-party videos". The email/phone extraction conflicts with privacy norms. Safe uses for CineFactory: Keywords, Trends, the Videos and Channels grids (metadata only), Tag and Title analyzers, and Comments (viewer-needs research), all read-only. The niche benchmark should still be the median, which Tube Atlas does not compute. Export the grid, or save an HTML report, and run `tools/cf_research_stats.py` on it to get medians and outliers.
- Because the app scrapes YouTube from the user's own computer (Windows is supported), it can run on the owner's CINE Windows machine. Heavy extraction may hit "too many requests" limits.

### Gaps
- No keyboard shortcuts, command-line options, URL parameters or API are documented anywhere official.
- How "Source" and "Search Phrase" are filled in for Browse & Extract imports versus keyword searches is not explained.
- The contents of help videos 1–44 and the update videos were not accessible here. Someone with a browser could watch them at https://appbreed.com/help-videos-tube-atlas to confirm click paths, the earnings formula, the report formats and the filter logic.
